# 壳层外观 · 浅色优先

Design Standard: Leego Design UI
Standard ID: leego-design-ui
Version: 2.31.0
契约：`shell-appearance-1`

黑色左侧菜单栏退出历史舞台。浅色优先对齐 Codex / Grok Bot 的工作壳：浅色导航铬层、深色文字、1px 分隔，而不是大块黑底。

## 覆盖全部表面

同一规则适用于：

- 外部 Web 与企业 Web 工作台
- 移动 Web
- Android
- iOS
- Pad
- 产品壳层，包括小字辈（小葡萄、小红花、小算盘、小金矿、小葫芦、小紫薯、小太阳、小点位、元码象、溯源狸、小总管，以及同一产品身份家族的其他成员）

官网、对话画布、原生底栏和 Pad 侧栏都走这套外观。几何、槽位和账号归属仍以各平台契约为准，不因为改色去改 216/68/248px 或原生 dp。

## 默认与深色入口

| 模式 | 何时使用 | 导航铬层 |
|---|---|---|
| `light`（默认） | 未声明外观，或系统为浅色 | 浅色 `#F7F8FA`，文字 `#172033`，分隔 `#E9EBEF` |
| `system` | 显式跟随系统 | 只读 `prefers-color-scheme` |
| `midnight` | 用户选了 Midnight | `#10161D` |
| `oled` | 用户选了 OLED | `#000000` |

深色铬层**只**来自系统 `prefers-color-scheme: dark`，或显式的 Midnight / OLED。浅色外观下不得默认深色或黑色左侧导航，也不得把黑白块面侧栏当成产品样子。

历史默认 `#111114` 侧栏，以及对话画布把 `#10161D` 当作浅色默认，都已退出。它们只保留为 Midnight 附近的深色令牌，不能再当 light 的底。

选中面仍是单一紫色 `#A18DF7`、选中文字 `#111114`。这是选中指示，不是把整条导航涂黑。

## 什么不是导航铬层

- 品牌图标的黑底变体、Geetimer 黑底 App 图标、单色反白稿，只用于图标资产或受限工艺。
- 小字辈的彩色身份留在符号和品牌点上，不铺成黑色导航或黑白块面侧栏。
- 官网可以有编辑节奏上的深浅章节，但导航和页面底色仍浅色优先；整页深色只走系统或 Midnight / OLED。

## P0 漂移

浅色外观（`light`，或 `system` 且系统不是 dark）下出现近黑导航铬层，审计为 **P0**。包括：

- 默认黑色左侧菜单
- 浅色内容旁边的黑色或黑白块面侧栏
- 用「品牌感」「高级感」把 light 模式的导航改回 `#111114` 或 `#10161D`

`scripts/audit-sidebar.mjs` 的 `sidebar.surface` 在未授权深色时把近黑底记为失败，证据标明 P0。Midnight / OLED，或系统深色且外观为 `system`，才允许深色铬层。探针通过不代替各平台真机验收。

宿主用 `data-leego-appearance="light|system|midnight|oled"` 放在根节点或侧栏上。缺省按 `system` 理解：浅色系统保持浅色，深色系统才切换。显式 `light` 在系统为深色时仍锁定浅色。
